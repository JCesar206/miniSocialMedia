# Mini Social Network React + Tailwind
This project, built with React + Tailwind, allows you to add comments and images, which are temporarily saved in the website's local storage.<br>
It allows you to edit and delete added comments.<br>
It also allows you to clear the form before submitting information.<br>
It features a footer with modern icons and links to social networks.<br>
Project with improvements pending.<br>
